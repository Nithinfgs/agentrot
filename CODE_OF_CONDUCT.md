# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

**Our standard.** Be respectful and constructive. Assume good faith. Critique code and ideas, not people. Harassment, discrimination, personal attacks, and publishing others' private information are not acceptable.

**Scope.** Applies in issues, pull requests, discussions and any space where someone represents the project.

**Enforcement.** Maintainers may edit or remove contributions and block participants who violate this. Report concerns by opening a private security advisory on the repository (Security tab) or by contacting the maintainer through their GitHub profile.
